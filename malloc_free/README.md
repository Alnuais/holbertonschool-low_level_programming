# C - malloc, free

This project introduces dynamic memory allocation in C.

## Learning objectives
- Understand automatic and dynamic memory allocation.
- Allocate memory using malloc.
- Release allocated memory using free.
- Understand memory leaks.

## Task 0
0-create_array.c creates an array of characters
and initializes every element with a specified character.

## Task 1 - String duplication
1-strdup.c duplicates a string using dynamically allocated memory.

## Task 2 - String concatenation
2-str_concat.c joins two strings into newly allocated memory.

## Task 3 - Grid allocation
3-alloc_grid.c creates a two-dimensional integer array
and initializes every element to zero.

## Task 4 - Grid cleanup
4-free_grid.c releases the memory allocated for the grid.
