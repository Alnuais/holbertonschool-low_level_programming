# C - Structures, typedef

This project introduces structures and typedef in C.

## Task 0 - Poppy
Define a dog structure with name, age and owner.

## Task 1 - Initialize dog
Initialize an existing dog structure.

## Task 2 - Print dog
Print the information stored in a dog structure.

## Task 3 - typedef
Create the alias dog_t for struct dog.

## Task 4 - Create dog
Dynamically allocate a dog and copies of its strings.

## Task 5 - Free dog
Release all dynamically allocated dog memory.
